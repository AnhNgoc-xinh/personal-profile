# Personal Profile Website

## 1. Giới thiệu
Website Portfolio giới thiệu thông tin cá nhân, kỹ năng và các nội dung liên quan. Website có khu vực quản trị để cập nhật nội dung.

## 2. Công nghệ sử dụng
- Python
- Flask
- HTML, CSS, JavaScript
- SQLite (phiên bản hiện tại)

## 3. Cấu trúc dự án
- `app.py`: chương trình Flask
- `templates/`: các trang giao diện HTML
- `static/`: tài nguyên tĩnh
- `requirements.txt`: danh sách thư viện cần cài đặt (nếu có)

## 4. Chạy ứng dụng
Tạo và kích hoạt môi trường Python ảo, sau đó cài các thư viện cần thiết và chạy:

```bash
source venv/bin/activate
python app.py
```

Mở địa chỉ được ứng dụng thông báo trên trình duyệt.

## 5. Triển khai hệ thống
Các cấu hình Docker Compose, MySQL, phpMyAdmin, Nginx, Prometheus, Grafana, Loki và Promtail sẽ được bổ sung khi triển khai và kiểm thử thực tế.
